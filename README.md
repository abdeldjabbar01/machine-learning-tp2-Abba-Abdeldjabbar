# ML TP2 – Standardized PCA

Implementation of standardized PCA from scratch (NumPy/Pandas), compared with Scikit-learn's `PCA`.

- **Data:** grades of 6 students in 4 subjects.
- **Notebook:** `TP-02-ABBA-Abdeldjabbar.ipynb` (run the cells in order).
- **Result (Part A):** PC1 = 93.49 %, PC2 = 6.01 % → the first two components keep **99.50 %** of the variance.
- **Requirements:** Python 3, numpy, pandas, scikit-learn, matplotlib.
